Deployment to GitHub Pages:
1. Create a repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings > Pages > Deploy from branch > main / root.
4. Add vyrencars.com as the custom domain when ready.
5. Configure the DNS records at your domain provider as GitHub instructs.

Before public launch:
- Replace legal placeholders with correct German legal/privacy information.
- Connect the sponsor form to a real form/email backend.
- Add real social links and team information.
- Replace/add renders or GLB model as desired.
